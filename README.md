# AI Resume Analyzer

A simple Python-based Resume Analyzer that compares a resume with a job description and identifies matching and missing skills.

## Features

- Resume and job description analysis
- Required skill detection
- Matching skill detection
- Missing skill detection
- Skill aliases such as JS → JavaScript and DSA → Data Structures
- Resume match percentage
- Resume strength feedback
- Improvement suggestions

## Technologies Used

- Python
- Regular Expressions
- Git
- GitHub

## How It Works

```text
Resume + Job Description
          ↓
     Skill Detection
          ↓
    Skill Comparison
          ↓
     Match Percentage
          ↓
  Feedback & Suggestions
